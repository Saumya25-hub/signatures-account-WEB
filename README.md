# Signatures Account Web Portal

Web presentation and user portal for the **Signatures ERP & Business Account** desktop suite.

---

## Overview

The Signatures Account Web Portal provides an interactive frontend interface designed to showcase features, modular architecture, pricing tiers, and client user management for the Signatures ERP ecosystem.

---

## Highlights & Features

- **Modern Responsive UI**: Clean layout built with semantic HTML5 and vanilla CSS3 styling.
- **Product Showcase & Feature Tour**: Highlights enterprise accounting workflows, GST capabilities, and multi-branch management.
- **Client Portal & Pricing Matrix**: Structured presentation for different software editions and service tiers.
- **Fast & Dependency-Free**: Lightweight, standalone frontend with zero external build dependencies.

---

## Structure

```
├── index.html        # Main landing page & hero showcase

├── contact.html      # Inquiry and support channel
```
